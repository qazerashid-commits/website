### Prerequisites

Before you begin, ensure you have met the following requirements:

* [Git](https://git-scm.com/downloads "Download Git") must be installed on your operating system.
* No Python installation is required — this project uses only HTML, CSS, and JavaScript.

### Run Locally

To run **Grilli** locally, run this command on your git bash:

Linux and macOS:

```bash
sudo git clone https://github.com/Asiku-01/grilli.git
```

Windows:

```bash
git clone https://github.com/Asiku-01/grilli.git
```
